# Phase 13.3-04: Live Chat & Real-Time WebSocket Flow

## Overview
This document details the real-time WebSocket architecture implemented in `supporthub/backend/app/routers/ws/chat.py` and `supporthub/backend/app/ws/manager.py`.

---

## WebSocket Connection Sequence

1. **Client Handshake**: Frontend connects to `ws://<host>/ws/chat/{ticket_id}?token=<jwt_token>`.
2. **WebSocket Handshake Acceptance**: `await websocket.accept()`.
3. **Authentication Guard (`get_ws_user`)**: Decodes JWT from `?token=`, looks up `User` in PostgreSQL database. If invalid or expired, socket closes.
4. **Ticket ID Validation & Room Ownership Check (Anti-IDOR)**:
   - Validates `ticket_id` UUID syntax.
   - Looks up `Ticket` in PostgreSQL.
   - For `role == "customer"`: Enforces `ticket.customer_id == user.id`. If unowned, closes with code `4003` (Anti-IDOR guard).
5. **Room Registration**: Registers socket connection with `manager.connect(ticket_id, websocket)`.
6. **Presence Broadcast**: Broadcasts `presence` event to ticket room subscribers.

## Real-Time Message Processing Pipeline

```
Client sends JSON {"type": "message", "body": "What is the status of ORD-025?"}
       |
       v
1. Validate non-empty body
       |
       v
2. Insert Message into PostgreSQL (sender_type="customer")
       |
       v
3. Broadcast message event to ticket room WebSocket subscribers
       |
       v
4. Broadcast inbox_update event to Agent Dashboard stream
       |
       v
5. Trigger Background Task: handle_ai_response(body, ticket_id)
       |
       v
6. LiveChatAIAdapter.process_live_chat_message()
       |
       +---> Resolve server-side customer_id
       +---> Check Guest guard
       +---> AIOrchestrator.process_message()
       +---> Update Ticket status (Escalated/Resolved)
       +---> Insert AI Message into PostgreSQL (sender_type="ai")
       +---> Broadcast AI message & status update over WebSocket
```

## Channels Outbound Hooks
- **WhatsApp Integration**: If `ticket.channel == "whatsapp"`, triggers `_send_whatsapp_outbound()` to send the message payload to the Meta Cloud API.
- **Instagram Integration**: If `ticket.channel == "instagram"`, triggers `_send_instagram_outbound()` to send the text message to the Meta Instagram Graph API.
