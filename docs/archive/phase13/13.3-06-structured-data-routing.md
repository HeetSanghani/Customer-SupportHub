# Phase 13.3-06: Structured Data Routing Inspection

## Overview
This document traces how structured queries interact with the MySQL database tables via `ai/tools.py` and `data_access/loader.py`.

---

## Tool Registry Mapping (`ai/tools.py`)

```python
class ToolRegistry:
    def get_product(self, product_id: str) -> Optional[Product]: ...
    def get_order(self, order_id: str) -> Optional[Order]: ...
    def get_order_items(self, order_id: str) -> List[OrderItem]: ...
    def get_shipment_by_order(self, order_id: str) -> Optional[Shipment]: ...
    def get_payment_by_order(self, order_id: str) -> Optional[Payment]: ...
    def get_return(self, return_id: str) -> Optional[Return]: ...
    def get_refund(self, refund_id: str) -> Optional[Refund]: ...
    def get_customer_orders(self, customer_id: str) -> List[Order]: ...
```

---

## Table-by-Table Data Access Trace

1. **`company`**: Company metadata (ShopKart e-commerce platform).
2. **`categories`**: Product category hierarchy.
3. **`sellers`**: Seller details, linked via `seller_id`.
4. **`products`**: Product specifications, price, MRP, inventory status. Query: `get_product(product_id)`.
5. **`customers`**: Customer profiles, email, phone, shipping addresses.
6. **`orders`**: Customer orders, status (CONFIRMED, PROCESSING, DELIVERED, CANCELLED), total amount. Query: `get_order(order_id)` or `get_customer_orders(customer_id)`.
7. **`order_items`**: Individual line items, quantity, price. Query: `get_order_items(order_id)`.
8. **`payments`**: Payment method, payment status, transaction ID. Query: `get_payment_by_order(order_id)`.
9. **`shipments`**: Carrier name, tracking number, shipment status, estimated delivery. Query: `get_shipment_by_order(order_id)` or `get_shipment_by_tracking(tracking_number)`.
10. **`returns`**: Return ID, return status, return reason. Query: `get_return(return_id)`.
11. **`refunds`**: Refund ID, refund status, refund amount. Query: `get_refund(refund_id)`.

---

## Authorization Enforcer Integration
Before returning data from `_execute_tools()`, `AIOrchestrator.process_message()` passes the owner ID to `security_validator.validate_resource_ownership(customer_id, resource_owner_id)`. If unauthorized, the tool response is wiped and replaced with `Access Denied`.
