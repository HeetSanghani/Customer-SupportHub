# Phase 13.3-08: Knowledge Base & Quick Reply Routing

## Overview
This document examines how general FAQs, Knowledge Base articles, and Quick Replies are stored, retrieved, and matched within the AI architecture.

---

## Current Implementation Findings

### 1. Knowledge Base Articles (`KB-001` to `KB-005`)
- **Storage**: JSON file `knowledge_articles.json`.
- **Integration**: Integrated directly into `RAGPipeline`. Knowledge articles are indexed alongside policy documents during `RAGPipeline.initialize()`.
- **Retrieval**: When a user asks general how-to questions ("How do I track my shipment?"), `AIRouter` routes the query to `RouteType.RAG`, which retrieves relevant `KB` chunks.

### 2. Quick Replies & Greetings
- **Storage**: Intent classifier regex rules in `ai/intent.py`.
- **Pattern Matching**: Matches common conversational phrases:
  - Greetings: "hello", "hi", "hey", "good morning".
  - Gratitude: "thank you", "thanks", "appreciate it".
  - Support hours / Contact: "how can I contact support?", "what are support hours?".
- **Response Mechanism**: `AIOrchestrator` returns predefined, high-speed instant response templates without making database or LLM calls.

---

## Quick Reply vs. RAG Priority Matrix

| Query Category | Primary Handler | Retrieval Speed | Grounding Source |
|:---|:---|:---|:---|
| Greetings & Conversational Fillers | Quick Reply (Intent Regex) | < 5ms | Static Pattern |
| General How-To FAQs | RAG Pipeline | ~ 15ms | `knowledge_articles.json` |
| Specific Platform Policies | RAG Pipeline | ~ 15ms | `policies.json` |
