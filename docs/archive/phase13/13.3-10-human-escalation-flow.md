# Phase 13.3-10: Human Escalation & Handoff Flow

## Overview
This document inspects the human escalation triggers, sentiment analysis, ticket status mutation, and real-time agent inbox notification flow in `ai/escalation.py` and `LiveChatAIAdapter`.

---

## Escalation Triggers

### 1. Explicit Customer Request
- Keywords: `"agent"`, `"human"`, `"representative"`, `"supervisor"`, `"talk to a person"`, `"customer care"`.
- Action: `EscalationDecision(should_escalate=True, reason="EXPLICIT_HUMAN_REQUEST", priority="HIGH")`.

### 2. High Frustration & Negative Sentiment
- Keywords: `"unacceptable"`, `"horrible service"`, `"useless bot"`, `"scam"`, `"fraud"`, `"sue you"`, `"legal action"`.
- Frustration Score Tracking: In `ConversationContext`, score increases on repeated frustrated turns. When `frustration_score >= 3`, triggers escalation.
- Action: `EscalationDecision(should_escalate=True, reason="HIGH_CUSTOMER_FRUSTRATION", priority="URGENT")`.

### 3. Repeated Unresolved Queries
- Triggers when the AI fails to resolve a query or detects repeated clarification loops over 3 consecutive turns.
- Action: `EscalationDecision(should_escalate=True, reason="UNRESOLVED_CONVERSATION_LOOP", priority="MEDIUM")`.

---

## End-to-End Execution Trace (`LiveChatAIAdapter`)

```
User message triggers escalation
       |
       v
AIOrchestrator returns AIResponse(escalation_decision=EscalationDecision(...))
       |
       v
1. LiveChatAIAdapter updates PostgreSQL Ticket:
   ticket.status = TicketStatus.escalated
   ticket.priority = TicketPriority.high (or urgent/medium)
   ticket.category = "Escalation"
   await session.commit()
       |
       v
2. Broadcast ticket update to Agent Dashboard Inbox:
   await manager.broadcast_to_agents({
       "type": "inbox_update",
       "ticket_id": ticket_id,
       "preview": "Customer requested human escalation: ...",
       "status": "escalated"
   })
       |
       v
3. Hold Notice on Subsequent Customer Messages:
   If ticket.status == TicketStatus.escalated:
       Returns: "Your request is with a human support agent. An agent is reviewing your inquiry and will respond shortly."
```
