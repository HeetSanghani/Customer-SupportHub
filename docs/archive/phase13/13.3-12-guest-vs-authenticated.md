# Phase 13.3-12: Guest vs. Authenticated Customer Behaviors

## Overview
This document compares system permissions, access controls, and contextual capabilities between **Guest Users** (unauthenticated / unlinked users) and **Authenticated Customers** (linked to `CUST-xxx`).

---

## Behavior Matrix

| Feature / Inquiry Area | Guest / Unlinked User (`GUEST` / `customer_id=None`) | Authenticated Customer (`customer_id="CUST-001"`) |
|:---|:---|:---|
| **Product Specifications & Prices** | **ALLOWED** (Public Product Data) | **ALLOWED** (Public Product Data) |
| **Company Policies (Return, Refund, Shipping)** | **ALLOWED** (RAG Knowledge Base) | **ALLOWED** (RAG Knowledge Base) |
| **General FAQs & Quick Replies** | **ALLOWED** (RAG / Instant Templates) | **ALLOWED** (RAG / Instant Templates) |
| **Personal Orders ("Where is my order?")** | **BLOCKED** (Prompted to Log In) | **ALLOWED** (Scoped to own orders) |
| **Personal Payments ("What payment did I use?")** | **BLOCKED** (Prompted to Log In) | **ALLOWED** (Scoped to own payments) |
| **Personal Shipments ("Where is my shipment?")** | **BLOCKED** (Prompted to Log In) | **ALLOWED** (Scoped to own shipments) |
| **Personal Returns / Refunds** | **BLOCKED** (Prompted to Log In) | **ALLOWED** (Scoped to own returns) |
| **Context Memory Slot Persistence** | **BLOCKED** (Guest Guard wipes transactional slots) | **ALLOWED** (Scoped active entity persistence) |

---

## Code Inspection: Guest Guard (`LiveChatAIAdapter`)

```python
# GUEST / Anonymous guard for private data requests in LiveChatAIAdapter
private_keywords = ["order", "payment", "shipment", "return", "refund", "my account", "my order", "my refund"]
msg_clean = message_body.lower()
if (customer_id_str == "GUEST" or not customer_id_str.startswith("CUST-")) and any(kw in msg_clean for kw in private_keywords):
    login_notice = (
        "You are currently chatting as a Guest. "
        "To view your personal order, payment, shipment, return, or refund details, "
        "please log in to your authenticated ShopKart account."
    )
    return login_notice
```

In `ConversationContext.update_slots_domain_aware()`, if `_is_guest = (self.customer_id is None or str(self.customer_id).upper() in ("GUEST", ""))`, all explicit order, return, and refund entity assignments are stripped to `None`.
