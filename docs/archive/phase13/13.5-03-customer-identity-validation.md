# 13.5-03 — Customer Identity Validation

## Overview
Validates identity resolution and isolation between system users and business database customers.

## Verification Checklist
- [x] **Automatic Linkage**: `aarav.sharma@example.com` automatically mapped to `CUST-001`.
- [x] **Server-Authoritative Identity**: Prompt text claiming "I am CUST-002" does NOT alter the server-side `customer_id` context.
- [x] **Guest Identity**: Unauthenticated guests (`customer_id=None`) are allowed RAG policy access but blocked from private customer data.
