# 13.5-02 — Authentication Validation

## Overview
Validates authentication mechanisms across REST endpoints, WebSocket connections, and user roles.

## Verification Checklist
- [x] **Registration Endpoint (`/api/v1/auth/register`)**: Creates password hashes using bcrypt; auto-binds customer identity.
- [x] **Login Endpoint (`/api/v1/auth/login`)**: Returns standard Bearer JWT tokens with sub and role claims.
- [x] **Protected Endpoints (`/api/v1/auth/me`)**: Rejects requests lacking token or with invalid signatures (401 Unauthorized).
- [x] **WebSocket Auth (`/ws/chat/{ticket_id}?token=...`)**: Enforces room guards and anti-IDOR checks (Close Code 4003 on ticket mismatch).
