# Phase 13.2 Remediation Plan

## Goal Description
Remediate the two root causes identified during Phase 13.2 manual validation testing:
1. **Shipment Intent Recognition & Context Isolation**:
   - Update `IntentClassifier` in `supporthub-ai-architecture/ai/intent.py` to recognize natural shipment phrases ("Where is my shipment?", "Where is my package?", "Where is my delivery?", "Track my shipment", "Track my package", "What's happening with my shipment?", "When will my shipment arrive?").
   - Refactor context slot merging in `IntentClassifier.classify()` to ensure active `product_id` context does NOT force unrelated queries into `PRODUCT_INQUIRY`.
2. **MySQL Database MRP Schema Alignment**:
   - Update `scripts/init_mysql_schema.py` and `scripts/migrate_json_to_mysql.py` to include `mrp DECIMAL(10,2)`.
   - Apply `ALTER TABLE products ADD COLUMN mrp DECIMAL(10,2) AFTER price;` and re-populate the database so live MySQL data contains genuine MRP values.
   - Verify discount percentage calculations across all data access layers.
