# 13.5-16 — Error Handling & Resilience Validation

## Overview
Validates system behavior under unexpected errors and simulated component outages.

## Scenarios
- **Unknown Entity**: Requesting non-existent order `ORD-999` returns clean fallback without stack traces.
- **Database Outage Simulation**: Simulated MySQL connection failure returns graceful error message without leaking connection strings or credentials.
- **LLM Timeout**: Fallback to rule-based intent matching when LLM times out.
