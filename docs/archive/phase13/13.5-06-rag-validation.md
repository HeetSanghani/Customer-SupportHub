# 13.5-06 — RAG Validation

## Overview
Validates vector search and grounded response generation for company policies.

## Tested Scenarios
- **Return Policy**: Grounded response retrieved from ShopKart Return Policy document.
- **Cancellation Policy**: Accurate timeframe (within 24 hours prior to dispatch) retrieved from knowledge base.
- **Payment Methods Policy**: Supported payment options correctly rendered.
- **Hallucination Prevention**: Irrelevant or out-of-scope policy queries safely fall back without inventing rules.
