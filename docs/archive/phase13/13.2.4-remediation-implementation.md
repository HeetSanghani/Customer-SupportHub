# Phase 13.2.4 — Contextual Reference Resolution Remediation Implementation

### 1. `ai/intent.py` (`IntentResult` Dataclass & `IntentClassifier.classify()`)

- Ensures `explicit_entities` contains ONLY entities directly extracted from the current query string (via `self.extract_entities(query)`), preventing context-inherited slots from leaking into explicit entity context.

### 3. `ai/context.py`
