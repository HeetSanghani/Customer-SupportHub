# Phase 13.2.5 — Implicit Reference Root Cause Analysis

## Exact Failure Mechanism

### Decision Chain
1. **Turn 1 (`ORD-025`)**: Persists `active_order_id = ORD-025`.
2. **Turn 2 (`PROD-002`)**:
   - `LLMIntentClassifier` or `RAG` route path processes `"Tell me about PROD-002."`.
   - In `LLMIntentClassifier.classify()`, the returned `IntentResult` does not set `explicit_entities`, defaulting to `{}`.
   - In `AIRouter.route()`, `context_slots.get("order_id")` is passed to `llm_classifier`, while `product_id` is ignored.
   - On `RouteType.RAG`, `AIOrchestrator` returns early without calling `update_slots_domain_aware()`.
   - As a result, `active_product_id` is **never persisted** and `active_order_id` is **never cleared**.
3. **Turn 3 (`"What is its price?"`)**:
   - Query contains no explicit entities.
   - `IntentClassifier` receives `context_slots` with `order_id = "ORD-025"` and `product_id = None`.
   - `_context_only_order = (not _has_any_explicit) and bool(context_entities.get("order_id"))` evaluates to `True`.
   - `IntentClassifier` classifies query as `ORDER_INQUIRY` for `ORD-025`.
   - System fetches and returns `ORD-025` data.

## File and Function Identification

| Component | File | Function | Exact Issue |

| `LLMIntentClassifier` | `ai/intent.py` | `classify()` | `explicit_entities` parameter omitted from `IntentResult` return (line 435); signature only takes `active_order_id` |
| `AIRouter` | `ai/router.py` | `route()` | Line 87 extracts `context_slots.get("order_id")` only and ignores `product_id`, `return_id`, `refund_id` |
| `AIOrchestrator` | `ai/orchestrator.py` | `process_message()` | Line 113 (`RAG` route) returns early without calling `update_slots_domain_aware()` |
| `IntentClassifier` | `ai/intent.py` | `classify()` | Line 295 `_context_only_order` assumes `order_id` in context without checking if a prior product turn occurred |

## Recommended Future Remediation (Do NOT implement in this phase)
1. **Update `LLMIntentClassifier`**: Support `explicit_entities` and pass all domain slots (`active_product_id`, `active_order_id`, etc.) in signature, prompt, and fallback.
2. **Update `AIRouter.route()`**: Pass full `context_slots` dictionary to `llm_classifier.classify()`.
3. **Update `AIOrchestrator`**: Ensure domain-aware slot updates run for all route types containing explicit entities (including `RAG` and `HYBRID`).
