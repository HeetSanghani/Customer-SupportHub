# 13.5-08 — Hybrid Routing Validation

## Overview
Validates hybrid intent processing combining structured database lookups with RAG knowledge rules.

## Scenarios
1. **"Can I cancel ORD-025?"**: Fetches order `ORD-025` status (`CONFIRMED`) from MySQL + evaluates against Cancellation Policy RAG -> Returns affirmative response with cancellation instructions.
2. **"Can I return ORD-025?"**: Combines MySQL delivery timestamp with Return Policy RAG -> Evaluates eligibility.
3. **"Why is my refund delayed?"**: Combines refund record status from MySQL + Refund Policy SLAs.
